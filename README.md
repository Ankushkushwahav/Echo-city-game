# ECHO CITY — The Decision Protocol

A futuristic browser game where your decisions permanently change the city.

## Included
- Playable Phaser-style canvas game built with React + HTML Canvas
- Keyboard + mobile touch controls
- Story missions and branching decisions
- NPC interactions
- Coins, XP, levels and inventory
- Dynamic day/night cycle
- Weather events
- Local save system
- Shop and upgrades
- Achievements
- Leaderboard demo
- Express API starter for future cloud persistence

## Run
```bash
npm install
npm run dev
```
Client: http://localhost:5173
API: http://localhost:4000

## Build
```bash
npm run build
```

The game is intentionally dependency-light so it can be deployed easily. For production multiplayer, connect the included Express API to MongoDB and Socket.IO.
